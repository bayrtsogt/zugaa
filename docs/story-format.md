# Өгүүллэг JSON-оор оруулах

Админ → **JSON оруулах** (`/admin/import`): JSON буулгах эсвэл нэг/олон `.json` файл сонгох (чирж оруулж болно) →
**Шалгах** → **Оруулах**. Нэг файлд нэг өгүүллэг, массив (`[ {...}, {...} ]`) эсвэл `{ "stories": [...] }` байж болно.

- Өгүүллэг бүр тусдаа транзакцаар орно (бүгд эсвэл юу ч үгүй).
- Ижил `slug`-тай өгүүллэг байвал мэдээлэл болон бүлгүүд **дугаараар нь шинэчлэгдэнэ**. Бүлэг устгагдахгүй тул
  уншигчдын худалдан авалт, уншсан газар хадгалагдана. Бүлэг устгах бол админ хэсгээс гараар устгана.
- «Шууд нийтлэх»-ийг сонгоогүй бол шинэ өгүүллэг/бүлэг ноорог болж орно.

## Талбарууд

| Талбар | Заавал | Тайлбар |
| --- | --- | --- |
| `title` | тийм | Гарчиг |
| `slug` | үгүй | URL (`/s/<slug>`). Байхгүй бол гарчгаас латинчилж үүсгэнэ |
| `description` | үгүй | Тайлбар |
| `genre` | үгүй | `horror`, `thriller`, `mystery`, `romance`, `other` |
| `age_rating` | үгүй | `all`, `16`, `18` |
| `price_coins` | үгүй | Бүтэн өгүүллэгийн үнэ (coin) эсвэл `null` |
| `wait_free_hours` | үгүй | Хүлээж үнэгүй унших цаг эсвэл `null` |
| `cover_url` | үгүй | `https://` зураг. Байхгүй бол төрлийн зураас-зураг харагдана |
| `chapters[].number` | тийм | 1-ээс эхэлсэн дугаар |
| `chapters[].title` | тийм | Бүлгийн гарчиг |
| `chapters[].content` | тийм | Markdown: догол мөрийг хоосон мөрөөр, `*налуу*`, `**тод**` |
| `chapters[].free` | үгүй | `true` бол үнэгүй |
| `chapters[].price_coins` | үгүй | Анхдагч 40 |
| `chapters[].ending` | үгүй | Салаалсан өгүүллэгийн төгсгөл |
| `chapters[].choices` | үгүй | `[{ "label": "Хаалгыг онгойлгох", "goto": 2 }]` |

Сонголтгүй, `ending` биш бүлгийн дараа уншигчид «Дараагийн бүлэг» (дугаараар дараагийнх) харагдана.

## AI-д өгөх prompt

```text
Чи Монгол хэлээр уран зохиол бичдэг мэргэжлийн зохиолч. «Зугаа» апп-д бүлэг бүлгээр уншигдах өгүүллэг бичнэ.

## Даалгавар
Төрөл: [аймшиг / триллер / нууцлаг / хайр дурлал / бусад]
Сэдэв / санаа: [энд бичнэ]
Бүтэц: [шугаман, N бүлэг] ЭСВЭЛ [салаалсан: N шийдвэрийн цэг, цэг бүр 2 сонголт]
Насны ангилал: [all / 16 / 18]

## Бичих зарчим
1. Зөвхөн монгол кирилл үсгээр, Ө ө Ү ү зөв бичнэ. Ярианы зураасыг «—» тэмдгээр бичнэ.
2. Бүлэг бүр 1,200–2,500 тэмдэгт. Эхний 600 тэмдэгт нь түгжээтэй бүлгийн «урьдчилсан харагдац» болдог тул бүлгийг шууд үйл явдлаар эхлүүл.
3. Эхний 1–2 бүлэг үнэгүй («free»: true) бөгөөд уншигчийг дэгээдэх ёстой. Үнэгүй сүүлийн бүлэг хүчтэй асуулт, сэжүүрээр төгсөнө.
4. Бүлэг бүр өөрийн жижиг эргэлттэй, сүүлийн мөр нь дараагийнхийг унших хүсэл төрүүлнэ.
5. Харуул, бүү тайлбарла: мэдрэмжийг үйлдэл, дуу чимээ, үнэр, жижиг нарийн ширийнээр илэрхийл. Аймшгийг цус биш, уур амьсгалаар бүтээ.
6. Дүр бүр тодорхой зорилготой. Монгол орчин (хот, хөдөө, өвөлжөө, сум, байр) болон нэрсийг бодитой ашигла.
7. Салаалсан бол:
   - Сонголт бүр бодит үр дагавартай, хоёр сонголт хоёулаа утга учиртай байна (зөв/буруу биш).
   - Сонголтын шошго богино, үйл үгээр эхэлнэ (40 тэмдэгтээс бага): «Хаалгыг онгойлгох», «Түүнд итгэх».
   - Шийдвэрийн цэгт хүрэх бүлэг нь хоёр сонголтыг тодорхой тавиад зогсоно.
   - Төгсгөл бүр «ending»: true, «**Төгсгөл.**» гэж дуусна. Төгсгөлүүд олон янз: аз жаргалтай, гашуун, гэнэтийн.
8. Насны ангилал «all» эсвэл «16» бол бэлгийн, хэт харгис дүрслэл оруулахгүй.
9. Хэлбэржүүлэлт: догол мөрийг хоосон мөрөөр тусгаарла (JSON дотор "\n\n"). *налуу*, **тод**-оос өөр тэмдэглэгээ, гарчиг, HTML, зураг бүү ашигла.

## Гаралт
ЗӨВХӨН доорх бүтэцтэй, хүчинтэй JSON буцаа. Тайлбар, markdown код блок бүү нэм.
- «number» 1-ээс дараалсан. Салаалсан бол сонголт «goto»-гоор зорилтот бүлгийн дугаарыг заана.
- «genre»: horror | thriller | mystery | romance | other
- «age_rating»: all | 16 | 18
- «slug»: латин жижиг үсэг, зураас (жишээ нь "harankhui-gudamj")
- «price_coins» (бүтэн өгүүллэг) ойролцоогоор нийт төлбөртэй бүлгүүдийн 60–70%. Бүлэг бүр 40.
```
