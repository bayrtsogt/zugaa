# Өгүүллэг JSON-оор оруулах

Админ → **JSON оруулах** (`/admin/import`): JSON буулгах эсвэл нэг/олон `.json` файл сонгох (чирж оруулж болно) →
**Шалгах** → **Оруулах**. Нэг файлд нэг өгүүллэг, массив (`[ {...}, {...} ]`) эсвэл `{ "stories": [...] }` байж болно.

- Өгүүллэг бүр тусдаа транзакцаар орно (бүгд эсвэл юу ч үгүй).
- Ижил `slug`-тай өгүүллэг байвал мэдээлэл болон бүлгүүд **дугаараар нь шинэчлэгдэнэ**. Бүлэг устгагдахгүй тул
  уншигчдын худалдан авалт, уншсан газар хадгалагдана. Бүлэг устгах бол админ хэсгээс гараар устгана.
- «Шууд нийтлэх»-ийг сонгоогүй бол шинэ өгүүллэг/бүлэг ноорог болж орно.
- Админ → өгүүллэг → **JSON татах**: өгүүллэгийг яг энэ форматаар татаж, засаад буцааж оруулна.

## Зураг

Зургийг админ хэсгээс оруулна (файл сонгох эсвэл чирэх — браузер дээр 1600px WebP болгож шахаад Supabase Storage-ийн
`media` bucket руу хуулна): өгүүллэгийн хавтас (3:4), бүлгийн зураг (3:2, гарчгийн доор), сонголт бүрийн зураг
(4:3 карт). JSON-оор текстээ дахин оруулахад зураг арилахгүй.

## Бүлэг бүлгээр (цуврал) оруулах

Урт өгүүллэгийг AI нэг дор бичиж чадахгүй тул ээлжээр оруулна:

1. **Эхний ээлж**: бүх талбартай JSON (`title`, `genre`…) + 1–3-р бүлэг.
2. **Дараагийн ээлж**: зөвхөн `{ "slug": "...", "chapters": [ ... ] }`. `title` байхгүй бол апп тухайн `slug`-тай
   өгүүллэгт бүлгүүдийг нэмнэ, өгүүллэгийн бусад мэдээллийг өөрчлөхгүй. Ийм өгүүллэг байхгүй бол алдаа гарна.
3. **Засах**: ижил `number`-тэй бүлгийг бүтнээр нь дахин оруулахад солигдоно (худалдан авалт хадгалагдана).
4. Нэг өгүүллэгийн хэд хэдэн ээлжийг (ижил `slug`) нэг дор буулгаж/файлаар оруулбал апп нэгтгэнэ.

Сонголт хараахан бичигдээгүй бүлэг рүү (`goto`) заавал тэр бүлэг нуугдмал ноорог болж үүснэ. Уншигчид сонголт
харагдахгүй, «Үргэлжлэл удахгүй гарна» гэж гарна. Тэр бүлгийг оруулахад сонголт автоматаар гарч ирнэ.

## Талбарууд

| Талбар | Заавал | Тайлбар |
| --- | --- | --- |
| `title` | шинэ өгүүллэгт | Гарчиг. Дараагийн ээлжинд орхино |
| `slug` | үгүй | URL (`/s/<slug>`). Байхгүй бол гарчгаас латинчилж үүсгэнэ |
| `description` | үгүй | Тайлбар |
| `genre` | үгүй | `horror`, `thriller`, `mystery`, `romance`, `other` |
| `age_rating` | үгүй | `all`, `16`, `18` |
| `price_coins` | үгүй | Бүтэн өгүүллэгийн үнэ (coin) эсвэл `null` |
| `wait_free_hours` | үгүй | Хүлээж үнэгүй унших цаг эсвэл `null` |
| `cover_url` | үгүй | `https://` зураг. Байхгүй бол төрлийн зураас-зураг харагдана |
| `chapters[].number` | тийм | 1-ээс эхэлсэн дугаар |
| `chapters[].title` | тийм | Бүлгийн гарчиг |
| `chapters[].content` | тийм | Markdown: догол мөрийг хоосон мөрөөр, `*налуу*`, `**тод**` |
| `chapters[].free` | үгүй | `true` бол үнэгүй |
| `chapters[].price_coins` | үгүй | Анхдагч 40 |
| `chapters[].ending` | үгүй | Салаалсан өгүүллэгийн төгсгөл |
| `chapters[].choices` | үгүй | `[{ "label": "Хаалгыг онгойлгох", "goto": 2 }]`, сонголт бүрт `image_url` байж болно |
| `chapters[].image_url` | үгүй | Бүлгийн зураг. Түлхүүр байхгүй бол дахин оруулахад одоо байгаа зураг хадгалагдана |
| `ongoing` | үгүй | `true`: цуврал үргэлжилж байна (сүүлийн бүлэгт «Үргэлжлэл удахгүй», дагагчдад мэдэгдэл) |

Сонголтгүй, `ending` биш бүлгийн дараа уншигчид «Дараагийн бүлэг» (дугаараар дараагийнх) харагдана.

## AI-д өгөх prompt

```text
Чи Монгол хэлээр уран зохиол бичдэг, олон бестселлертэй мэргэжлийн зохиолч. «Зугаа» апп-д утсаар бүлэг бүлгээр уншигддаг, уншигчийг салгаж болшгүй татдаг өгүүллэг бичнэ.

## Даалгавар
Төрөл: [аймшиг / триллер / нууцлаг / хайр дурлал / бусад]
Сэдэв / санаа: [энд бичнэ]
Бүтэц: [шугаман, 8–10 бүлэг] ЭСВЭЛ [салаалсан: 3 шийдвэрийн цэг, цэг бүр 2 сонголт]
Насны ангилал: [all / 16 / 18]
Нэг уншлагын урт: 30–40 минут (нэг замаар уншихад 6,000–8,000 үг)

## Ажлын дараалал (заавал мөрдөнө)
АЛХАМ 1 — ТӨЛӨВЛӨГӨӨ. Эхлээд JSON биш, энгийн текстээр:
  • slug, гарчиг, нэг өгүүлбэр тайлбар;
  • гол дүрүүд (нэр, нас, зорилго, нууц), орчин;
  • бүх бүлгийн жагсаалт: дугаар, гарчиг, 1–2 өгүүлбэр агуулга, үнэгүй эсэх;
  • салаалсан бол салааны зураглал: «3 → 4 (сонголт А) / 5 (сонголт Б)», төгсгөл бүрийн дугаар.
  Бүлгийн дугаарыг энэ төлөвлөгөөнд ТОГТООНО — дараа нь өөрчлөхгүй.
АЛХАМ 2 — 1–3-р бүлэг. Төлөвлөгөөний дараа ЗӨВХӨН 1–3-р бүлгийг доорх бүтэн JSON-оор гарга.
Дараагийн бүлгүүдийг «үргэлжлүүл» гэж хэлэхэд гаргана.

## Бичих зарчим
1. Урт: бүлэг бүр 800–1,200 үг (5,000–8,000 тэмдэгт). Үнэгүй бүлгүүд 600–900 үг байж болно.
2. Эхний 600 тэмдэгт: түгжээтэй бүлгийн «урьдчилсан харагдац» болдог. Шууд үйл явдал, дүр, хурцадмал байдлаар эхэл — цаг агаар, сэрэх, удиртгал тайлбараар бүү эхэл.
3. Үнэгүй бүлэг: 1–2-р бүлэг («free»: true). Хамгийн хүчтэй эргэлт эсвэл асуулт нь сүүлийн үнэгүй бүлгийн төгсгөлд байна — уншигч энд л зоос төлөх шийдвэр гаргана.
4. Cliffhanger: бүлэг бүр шинэ мэдээлэл, эргэлт, аюул эсвэл асуултаар төгсөнө. «Тэгээд унтлаа» маягийн тайван төгсгөл хориотой.
5. Хэмнэл: үзэгдэл бүр зөрчилтэй. Яриа, үйлдэл, дотоод бодлыг ээлжлүүл. Нэг догол мөр 2–5 өгүүлбэр (утсаар уншина).
6. Харуул, бүү тайлбарла: мэдрэмжийг үйлдэл, дуу чимээ, үнэр, жижиг нарийн ширийнээр илэрхийл. Аймшгийг цус биш, уур амьсгалаар бүтээ.
7. Монгол орчин: хот, хөдөө, сум, гэр хороолол, байр, бодит нэрс, ёс заншил. Орчуулгын хэллэг, «тэр эмэгтэй/тэр эрэгтэй»-г хэт давтахгүй.
8. Хэл: зөвхөн монгол кирилл, Ө ө Ү ү зөв. Яриаг шинэ догол мөрөөс «— » (урт зураас)-аар эхлүүл.
9. Тасралтгүй байдал: төлөвлөгөөний нэр, нас, газар, өмнөх бүлгийн баримтыг бүү өөрчил.
10. Салаалсан бол:
   - Шийдвэрийн цэг дээрх бүлэг хоёр сонголтыг тодорхой тавиад зогсоно; аль нь ч зөв/буруу биш, хоёулаа сонирхолтой үр дагавартай.
   - Сонголтын шошго үйл үгээр, 40 тэмдэгтээс богино: «Хаалгыг онгойлгох», «Түүнд итгэх».
   - «goto» нь төлөвлөгөөний бүлгийн дугаар. Хараахан бичээгүй бүлэг рүү заах нь зөв — тэр бүлэг орох хүртэл апп сонголтыг нууна.
   - Сонголтгүй, «ending» биш бүлгийн дараа апп дугаараар дараагийн бүлгийг нээнэ — салааны бүлгүүдийг үүнд тааруулж дугаарла.
   - Төгсгөл бүр «ending»: true, «**Төгсгөл.**» гэж дуусна. Төгсгөлүүд олон янз: аз жаргалтай, гашуун, гэнэтийн.
11. Насны ангилал «all» эсвэл «16» бол бэлгийн, хэт харгис дүрслэл оруулахгүй.

## JSON-ийн дүрэм (апп шууд уншина — алдаа гаргавал орохгүй)
- ЗӨВХӨН хүчинтэй JSON. Өмнө нь, ард нь тайлбар, ``` код блок БҮҮ нэм (АЛХАМ 1-ийн төлөвлөгөөнөөс бусад үед).
- Текст дотор " (давхар хашилт) БҮҮ хэрэглэ — «» хашилт хэрэглэ. Энэ нь JSON-г эвдэхээс сэргийлнэ.
- Догол мөрийг "\n\n"-ээр тусгаарла. Зөвхөн *налуу*, **тод**; гарчиг, HTML, зураг, emoji бүү ашигла.
- «slug»: латин жижиг үсэг, зураас (жишээ нь "harankhui-gudamj"). Бүх ээлжинд ИЖИЛ slug.
- «ongoing»: эхний ээлжинд true (апп «Үргэлжилж байна» гэж харуулж, дагагчдад шинэ бүлгийг мэдэгдэнэ). Зураг («image_url») бүү бич — админ дараа нь оруулна.
- «genre»: horror (Аймшиг) | thriller (Триллер) | mystery (Нууцлаг) | romance (Хайр дурлал) | other (Бусад)
- «age_rating»: all | 16 | 18
- Бүлгийн «price_coins»: ердийн 40, урт/оргил бүлэг 50–60. Өгүүллэгийн «price_coins» (бүгдийг нэг дор нээх) ≈ төлбөртэй бүлгүүдийн нийлбэрийн 60–70%.

## Үргэлжлэлийн prompt

```text
Үргэлжлүүл: төлөвлөгөөний дагуу [N]–[M]-р бүлгийг бич (нэг удаад 2–3 бүлэг).

- Өмнөх бүлгүүдийн дүр, нэр, баримт, хэв маяг, урттай (800–1,200 үг) яг нийцүүл. Төлөвлөгөөний бүлгийн дугаарыг өөрчлөхгүй.
- Бүлэг бүр cliffhanger-аар төгсөнө; салааны төгсгөл бол «ending»: true ба «**Төгсгөл.**».
- ЗӨВХӨН доорх JSON-г гарга: өгүүллэгийн бусад мэдээлэл (title, description, genre…) БҮҮ давт — апп ижил «slug»-аар өмнөх бүлгүүдтэй нэгтгэнэ.
- Тайлбар, код блок, текст дотор " хашилт бүү хэрэглэ («» хэрэглэ).
- Аль нэг өмнөх бүлгийг засах бол тэр бүлгийг ижил «number»-тэй бүтнээр нь дахин гарга — апп солино.
- Энэ нь өгүүллэгийн СҮҮЛИЙН ээлж бол JSON-д "ongoing": false нэм.

{
  "slug": "harankhui-gudamj",
  "chapters": [
    {
      "number": 4,
      "title": "…",
      "free": false,
      "content": "…",
      "choices": [
        {
          "label": "…",
          "goto": 6
        },
        {
          "label": "…",
          "goto": 7
        }
      ]
    }
  ]
}
```
